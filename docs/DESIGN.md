# ЕлиГуси — визуальная система нового интерфейса (`frontend/`, этап 5)

Идея — **эмалированная кухонная посуда**. Приложение крутится вокруг кастрюли, а значит — белая эмаль, плотный
цветной ободок, как у советской эмалированной кастрюли, и белый гусь с оранжевым клювом из иконки. Смелость —
в одном месте: **ободок** у главных контейнеров (приём пищи, кастрюля, день). Всё остальное тихое.

## Цвет (токены — `frontend/src/styles/tokens.css`)

| Токен | Светлая | Тёмная | Где |
|---|---|---|---|
| `--tile` | `#EAF0EC` | `#0E1512` | фон страницы — «кафель» |
| `--enamel` | `#FDFEFD` | `#17201B` | поверхности — эмаль |
| `--enamel-2` | `#F2F6F3` | `#1E2924` | вложенные поверхности, поля |
| `--rim` | `#1F5C44` | `#5FB98E` | ободок, фирменный зелёный (как у иконки) |
| `--ink` | `#14201A` | `#E7EFEA` | текст |
| `--muted` | `#5C6B63` | `#93A49B` | второстепенный текст |
| `--beak` | `#E8832E` | `#F29A4E` | клюв: «сейчас» и главное действие «Съел» — не больше одного места на экране |
| `--graphite` | `#6F747C` | `#A2A8B0` | черновики автоплана («карандаш») |
| `--tomato` | `#C8432F` | `#EE6E59` | ошибки, перебор, просрочка |
| `--line` | `#D3DED7` | `#2A3830` | тонкие разделители |

Состояния блюда — как в старом плане: «приготовить» — `--beak` приглушённый (`--cook`), «в холодильнике» —
`--rim`, «готовый продукт» — `--sky` (`#2F6FAE` / `#79AEE6`).

## Шрифты

- **Unbounded** (variable, 300–700) — числа дат, заголовки экранов, крупные цифры КБЖУ. Широкий, округлый —
  «эмалевая» гарнитура. Только крупно (≥ 20 px), никогда для абзацев.
- **Golos Text** (variable, 400–700) — весь интерфейс и текст. Хорошая кириллица, спокойный.
- Свои, без сети (`@fontsource-variable/*`): приложение работает офлайн.
- Шкала (px): 12 · 14 · 16 (база) · 20 · 28 · 40. Межстрочный 1,45 для текста, 1,1 для Unbounded.
- Цифры — `font-variant-numeric: tabular-nums`. Метки — обычным регистром, без капса и разрядки.

## Форма

- **Ободок** (`.pot`): `border: 2px solid var(--rim)`, радиус 20 px — только главный контейнер экрана (на «Сегодня» —
  текущий приём пищи); соседние контейнеры той же формы — тонкой линией `--line`. Внутри — эмаль.
- Вложенное: радиус 12 px, без ободка, фон `--enamel-2`. Фишки и кнопки-переключатели — 999 px.
- Тени не используем (эмаль блестит, а не парит); отделение — цветом фона и ободком.
- Кнопки: главная — заливка `--rim` (или `--beak` для «Съел»), вторичная — контур 1.5 px `--rim`, третья — текст.
- Минимальная цель касания 44 × 44 px (кухня, мокрые руки, магазин).

## Раскладка

- Телефон — главный экран. Нижняя панель: **Сегодня** · План · Покупки · Холодильник · Ещё. Отступы 16 px.
- Компьютер (≥ 900 px): слева узкая колонка навигации, контент до 760 px для «Сегодня», шире — для недели.
- Выравнивание — по левому краю. Числа справа в строках.

## Движение

Одно место: при «Съел» карточка приёма пищи «наполняется» (фон слева направо, 250 мс). Остальное — без анимаций.
`prefers-reduced-motion` — без движения вовсе.

## Текст

Глаголы и конкретика: «Съел», «Приготовить», «Принять». Ошибки — что случилось и что сделать, без извинений.
Пустые состояния — приглашение к действию («На сегодня ничего не запланировано — предложить?»).
